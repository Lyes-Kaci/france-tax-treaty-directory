# Périmètre public

## Inclus

- l’application autonome actuellement intégrée à la page « Conventions fiscales » ;
- la totalité du catalogue public utilisé par cette application ;
- 128 juridictions ;
- 255 références de conventions, avenants, échanges de lettres, arrangements et autres instruments recensés ;
- sept instruments signés non encore entrés en vigueur ;
- les impôts couverts, mentions, renvois, statuts particuliers et liens documentaires affichés publiquement ;
- les ressources OCDE déjà proposées dans l’interface publique.

## Non inclus

- le corpus mondial de conventions fiscales ;
- les fichiers PDF ou textes intégraux hébergés par les sources officielles ;
- les bases, exports, règles, clauses, moteurs ou architectures ANNA/LUM ;
- les analyses internes, audits, journaux de collecte et preuves de travail ;
- toute conclusion automatique sur l’applicabilité d’un instrument.

Le dépôt constitue donc la publication complète du **corpus public de la page française**, et non celle des autres corpus documentaires du titulaire.
